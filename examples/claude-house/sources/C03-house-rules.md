# Rules for session hosts

## Claiming a slot

A host claims a slot in the backoffice. An organiser releases it. Only after the
release does the host request the event page and send the link back. A host cannot
issue a branded event link without going through that request.

## Event page requirements

- The event must be public, with a clear description and an event image.
- Address: Carrer de Bilbao 128.
- All hosts listed, with photo, bio and social links.
- Three named organisers added as co-hosts, so volunteers can check people in.
- **Maximum tickets equals room capacity plus 20 percent.**

## Expectations

Each ambassador runs at least one session of one to two hours. Up to three slots
can be claimed per ambassador.

## API credits

A credit link is available for workshop participants: 50 US dollars each, for the
API only, not for the chat product. The link accepts a fixed number of redemptions.
One redemption per person. Submissions with the wrong account ID cannot be fixed
afterwards.
