1 · The map problem

Not a memory problem.
A map problem.

Context is finite

Every token spends attention.

Loading everything is not an option.

So give the agent a map

Know where to look.

Then load only what the question needs.

2 · The LLM wiki pattern · what we added

Karpathy described it. We turned it into four commands.

/wiki-initA folder of documents becomes a wiki. Ingests every source oldest first, builds the fact sheet from the claims it finds, registers the wiki in the root map. Runs once per project.
/wiki-ingestOne source in, many pages out. Writes the summary, updates entities, proposes fact sheet changes and waits. The original is never edited, only moved.
/wiki-lintThe health check. Finds contradictions, duplicates, stale facts, orphans. Writes a dated report and changes nothing until you name a finding.
/wiki-queryAnswers from the wiki, not from memory, and shows the path it took. Offers to file a good answer back as a new page.

Four markdown files in .claude/skills/. Clone the repo, and they are in your slash menu. No install, no service, no key.

Own work: the four skills. Source of the pattern: Karpathy, llm-wiki.md (GitHub gist, April 2026).10 / 23

2 · The LLM wiki pattern · the lint up close

The lint reports. It does not repair.

Never silently fixThe report comes first. A finding is resolved when a human names its number, and the resolution is logged.
Newest is not automatically rightA newer source wins only if it owns the fact or says explicitly that it replaces the old one. Never resolve a contradiction by date alone.
Report only what you verifiedA script proposes candidates. Every one is checked by reading the pages before it reaches the report.
Every finding has an ownerThe fact sheet names the role that decides. A finding without an owner is itself a finding.

Two parts: .claude/skills/wiki-lint/SKILL.md is the procedure, scripts/check_links.py does the mechanical pass. Both in the repo.

Own work: the four rules, quoted from the skill. Source of the check list: Karpathy, llm-wiki.md (2026).11 / 23

Backup · only if the question comes up

Why not just retrieval?

Strong where this pattern is weak: huge corpora, unknown questions, a file indexed in seconds. Three things it gets wrong:

Chunk boundaries
“Revenue grew by 3%.” Which company? Which quarter?
No canonical fact
Last year's price list ranks as high as this year's.
Contradictions
Both versions reach the prompt. The model picks one.
And on my side
No chunking to tune, files I can read, Obsidian as the UI, running in an afternoon.
Sources: Anthropic, Contextual Retrieval (2024); Lewis et al., RAG, NeurIPS 2020; Sarthi et al., RAPTOR (2024); Wang et al., RAG with Conflicting Evidence, COLM 2025. Own observation: the canonical-fact row.19 / 23
