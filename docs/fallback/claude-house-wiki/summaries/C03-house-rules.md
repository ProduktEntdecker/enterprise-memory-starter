# C03 Rules for session hosts

> Up: [Claude House wiki index](../index.md)

## TL;DR

A host claims a slot in the backoffice, an organiser releases it, and only then may the host request the event page. The event page must be public, carry the house address, list all hosts and three named organisers as co-hosts, and sell at most room capacity plus 20 percent. Workshop participants can receive a 50 US dollar API credit, for the API only, one redemption per person and not correctable after a wrong account ID.

## Key points

- Slot process: claim in the backoffice, organiser releases, host then requests the event page and sends the link back. A host cannot issue a branded event link outside that process.
- Event page: public, clear description, event image, address Carrer de Bilbao 128.
- All hosts listed with photo, bio and social links. Three named organisers added as co-hosts so volunteers can check people in.
- Maximum tickets equals room capacity plus 20 percent.
- Each ambassador runs at least one session of one to two hours. Up to three slots per ambassador.
- API credit for workshop participants: 50 US dollars each, API only, not the chat product.
- The credit link accepts a fixed number of redemptions, one per person. A submission with the wrong account ID cannot be fixed afterwards.

## Open questions

- The ticket rule is a formula on room capacity, and the capacities changed on 2026-09-19 (C02). Event pages published before that date may still cap at the old capacity plus 20 percent. Which pages need a correction?
- How many redemptions does the credit link accept? The note says the number is fixed but does not give it.
- Which three organisers are the named co-hosts? The note requires three but names nobody.
