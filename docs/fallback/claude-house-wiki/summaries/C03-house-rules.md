# C03 Rules for session hosts

> Up: [wiki index](../index.md)

## TL;DR

A host claims a slot, an organiser releases it, and only then is the event page
requested. Tickets are capped at room capacity plus 20 percent. API credits exist
for workshop participants, but the source does not say how many redemptions the
link accepts.

## Key points

- The release by an organiser comes before the event page, not after
- A host cannot issue a branded event link on their own
- Event page requirements: public, clear description, image, the address, all hosts
  listed with photo and bio, three named organisers as co-hosts
- **Maximum tickets equals room capacity plus 20 percent**
- At least one session per ambassador, up to three slots
- API credits: 50 US dollars per person, API only, one redemption per person, and
  a wrong account ID cannot be fixed afterwards
